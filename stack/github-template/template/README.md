# {{ORG_NAME}}/.github

Account-wide defaults for every repository under [{{ORG_NAME}}](https://github.com/{{ORG_NAME}}).

GitHub reads this repo for any repository that does not ship its own copy of these files:

| File | What it does |
| --- | --- |
| `CODE_OF_CONDUCT.md` | How we treat each other in issues, PRs and discussions |
| `CONTRIBUTING.md` | How work flows: issue first, then a branch, then a PR |
| `SECURITY.md` | How to report a vulnerability privately |
| `SUPPORT.md` | Where to ask for help, and what to expect |
| `FUNDING.yml` | Sponsor button (off until a platform is filled in) |
| `.github/ISSUE_TEMPLATE/` | Bug, feature and chore forms |
| `.github/PULL_REQUEST_TEMPLATE.md` | The PR checklist |
| `workflow-templates/` | Starter CI offered in the Actions tab (organizations only) |
| `labels.yml` | The standard label set every repo should carry |
| `profile/README.md` | The profile page (see below) |

**Profile page.** For an organization, `profile/README.md` here *is* the page at
github.com/{{ORG_NAME}}. For a personal account, GitHub shows the README of the
`{{ORG_NAME}}/{{ORG_NAME}}` repository instead, so copy `profile/` there.

Rendered from the rio.stack GitHub template (`stack/github-template`, template v1).
Edit values there and re-render, or edit here directly; both are fine.

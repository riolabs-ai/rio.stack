# Profile

The profile page for [{{DISPLAY_NAME}}](https://github.com/{{ORG_NAME}}) lives in
**[{{ORG_NAME}}/{{ORG_NAME}}](https://github.com/{{ORG_NAME}}/{{ORG_NAME}})**.

GitHub renders a personal account's profile from the repository named after the account,
not from `.github/profile/` (that path is for organizations). The words come from
[`rio-template.values.yaml`](../rio-template.values.yaml) in this repo, so there is one
source and two outputs.

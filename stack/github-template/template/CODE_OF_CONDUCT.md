# Code of conduct

This applies to every repository, issue, pull request and discussion under
{{ORG_NAME}}.

## The short version

Be useful, be kind, assume good intent. Critique code and ideas, never people.

## What we expect

- Clear, respectful language, including when you disagree.
- Patience with newcomers and with questions that have been asked before.
- Accepting a "no" or a "not now" on a proposal without relitigating it everywhere.
- Owning mistakes, yours included, and fixing them in the open.

## What is not okay

- Harassment, insults, slurs or personal attacks, in public or in private.
- Sharing someone's private information without their permission.
- Sexualised language or imagery, and unwelcome attention of any kind.
- Repeatedly derailing threads or ignoring a maintainer's request to stop.

## What happens

Maintainers may edit or hide comments, lock threads, or block accounts that break
these rules. Serious or repeated cases are removed without warning.

## Reporting

Write to {{CONTACT_EMAIL}}. Reports are read only by the maintainers and kept private.
If the report involves a maintainer, say so and it will be handled by someone else.

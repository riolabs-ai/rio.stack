# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for a security problem.

1. Preferred: use **Report a vulnerability** on the affected repository's
   *Security* tab (GitHub private vulnerability reporting).
2. Otherwise, email {{SECURITY_EMAIL}} with the repository, what you found, and how
   to reproduce it.

You will get an acknowledgement within {{SECURITY_RESPONSE}}. Once a fix ships, you are
credited in the advisory unless you ask not to be.

## Supported versions

Only the latest release (or the default branch, for repos without releases) receives
security fixes.
